# Transaction_analysis

Проект для анализа банковских транзакций, включая отчеты, сервисы и веб-страницы.

## Структура проекта

Transaction_analysis/
├── src/ # Исходный код
│ ├── init.py
│ ├── utils.py # Вспомогательные функции
│ ├── main.py # Точка входа
│ ├── views.py # Функции для генерации JSON-ответов (веб-страницы)
│ ├── reports.py # Функции для генерации отчетов
│ └── services.py # Бизнес-логика (сервисы)
├── data/ # Данные
│ └── operations.xlsx # Файл с транзакциями
├── tests/ # Тесты
│ ├── init.py
│ ├── test_utils.py
│ ├── test_views.py
│ ├── test_reports.py
│ └── test_services.py
├── user_settings.json # Пользовательские настройки
├── .venv/ # Виртуальное окружение
├── .env # Переменные окружения
├── .env_template # Шаблон для .env
├── .git/
├── .idea/

├── .gitignore
├── pyproject.toml # Конфигурация проекта (Poetry)
├── poetry.lock
└── README.md # Этот файл

## Установка

1.  Убедитесь, что у вас установлен Python 3.8+ и Poetry.
2.  Клонируйте репозиторий.
3.  Перейдите в директорию проекта.
4.  Создайте виртуальное окружение и установите зависимости:
    ```bash
    poetry install
    ```
5.  Активируйте виртуальное окружение:
    ```bash
    poetry shell
    ```

## Конфигурация

*   **`user_settings.json`**: Укажите валюты и акции для отображения.
    ```json
    {
      "user_currencies": ["USD", "EUR"],
      "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
    }
    ```

## Использование

*   **Основной скрипт**: Запустите `src/main.py` (если реализован).

## Модули

*   **`src/utils.py`**: Вспомогательные функции для загрузки данных, фильтрации, работы с API.
*   **`src/views.py`**: Функции для генерации JSON-ответов для веб-страниц (например, "Главная").
*   **`src/services.py`**: Реализация бизнес-логики (например, "Инвесткопилка").
*   **`src/reports.py`**: Функции для генерации аналитических отчетов (например, "Траты по дням недели").

## Тестирование
